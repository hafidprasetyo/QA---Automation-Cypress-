# Cypress Automation Test - OrangeHRM Login

Project ini berisi automation testing fitur Login OrangeHRM menggunakan Cypress.

## Test Case:
1. Login valid
2. Username salah
3. Password salah
4. Username dan Password salah
5. Username kosong
6. Password kosong
7. Username dan Password kosong

## Cara Menjalankan:
```bash
npm install
npx cypress open
